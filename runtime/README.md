# ORION Runtime

The Python AI runtime (daemon) for ORION — voice pipeline, event bus, memory,
agent graph, MCP integrations, and the IPC transport to the client.

See the [repository README](../README.md) for the full project overview and
architecture. This package is developed from the `runtime/` directory:

```bash
cd runtime
uv sync
uv run python -m orion   # or: uv run orion
```
